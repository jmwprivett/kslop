# iOS 26 VM Control Center resource provenance

Status: the diagnostic extension is implemented and locally verified. A live
VM run of this extension has not yet been captured. This note does not claim
that a production theming adapter is installed or persistent.

## Why this trace exists

The ownership snapshots in `vphone-ios26-controlcenter-lifecycle-owners.md`
already identify the base and expanded Now Playing transport buttons, and the
expanded Focus rows. They prove direct routes to the current receivers, but
metadata and stable owner addresses do not prove which resource factory runs
again when a receiver is reconstructed.

The existing iOS 26 VM metadata contains these stock factory contracts:

| Source | Checked ABI | What the new trace records |
| --- | --- | --- |
| `MRUAssetsProvider` package-name getters | `@16@0:8` | Natural returned package names, distinct from snapshot reads |
| `MRUAssetsProvider packageWithName:` and `packageDescriptionWithName:` | `@24@0:8@16` | Name input, returned package/description, nested resource/cache calls |
| `FCUICAPackageView packageViewForActivity:` | `@24@0:8@16` | Activity identifier and symbol, returned icon package view |
| `CCUICAPackageDescription packageDescriptionForActivity:` | `@24@0:8@16` | Activity-to-package description selection |
| `CCUICAPackageDescription descriptionForPackageNamed:inBundle:` | `@32@0:8@16@24` | Package name, bundle URL, resulting description URL |
| `CAPackage packageWithContentsOfURL:type:options:error:` | `@48@0:8@16@24@32^@40` | Actual package URL, returned package address, root-layer address |
| `FCUIActivityControl _updateActivityIcon` and named icon setters | Exact runtime encodings | Activity machine identity and icon receiver before/after stock work |

The trace also observes the Media controller's stock `loadView`/`viewDidLoad`
and context factory, Focus picker's stock `loadView`/list configuration,
system-image factories, bundle resource resolution, and `NSCache` calls nested
inside those UI factory contexts. It does not enumerate or mutate a cache.
Canonical Media transport and Focus package URL loads can be observed even
when Swift calls the package loader without an `MRUAssetsProvider` parent.

## Diagnostic behavior

`scripts/lab/cnd_cc_resource_provenance.inc` is included only by the VM lab
ownership tracer. Observation is explicitly enabled with `resource-start`.
Each observer checks method ownership and the exact Objective-C encoding
before installation. All arguments and stock results are forwarded unchanged;
`NSError **` is forwarded directly without dereferencing or rewriting it.
This uses temporary method interception for diagnostics, not a production
adapter or artwork replacement.

Events carry sequence/parent sequence numbers, the operation phase, object
addresses, activity identifiers, package URLs, and symbol names. Addresses are
snapshot evidence only. The recorder uses no visible labels or geometry for
identity, and follows no UIKit descendant hierarchy. The existing optional
recursive discovery mode remains a separate snapshot feature.

Snapshot getter calls are suppressed in the observer so invoking a provider
getter to inspect it cannot masquerade as a natural factory consultation.
The recorder stores at most 4,096 events and reports dropped observations.
`resource-stop` and the whole tracer's `stop` restore each method only if its
current implementation is still this diagnostic's observer. Restoration
conflicts are reported instead of overwriting another replacement.

## VM exercise

Use the established vPhone lab connection and `CND_VPHONE_ROOT_PASSWORD`.
The launcher requires the VM identity marker and SSH port 22222.
Pass the same fresh `--output-dir` to each operation so the new captures remain
separate from historical ownership evidence.

1. Build/inject the ownership tracer, then enable `resource-start` with a
   descriptive `--phase`.
2. Capture base Control Center using `snapshot`, expand the media module,
   capture the expanded view, collapse/dismiss/reopen, and capture again.
3. Expand `com.apple.FocusUIModule`, capture its rows, invoke the existing
   `reconstruct-views` driver for that module, and capture the rebuilt rows.
4. Run `resource-stop`, capture the retained observations, and run `stop` to
   restore the existing reconstruction journal as well.
5. Run `cnd_cc_owner_analysis.py` over the artifacts and compare the relevant
   before/after phases.

Presentation/reconstruction operations accept `--phase`; that phase labels
factory events generated by the operation. Snapshots do not relabel earlier
events. A single observation session is supported per loaded tracer payload.

The summary's `resourceProvenance` records observed factory calls, package
loads, symbol calls and scoped cache calls. Returned Focus package-view
addresses join to named row slots. Loaded package root layers can join to
verified Media `packageLayer` fields or Focus `_rootLayer` slots. Unmatched
results remain unmatched; the analysis does not infer a connection from icon
appearance or resource filenames alone.

A comparison reports newly observed factory calls and newly created Focus
rows whose package-view address matches a factory result. Multiple phase
consultations alone do not prove new receiver generation. The existing Media
close/reopen/container-invalidation exercise retained its transport objects;
a fresh Swift receiver generation remains necessary to validate that case.

## Local verification

The iPhoneOS dylib builds with `-Wall -Wextra -Werror`. Python evidence tests
verify that static metadata does not become execution evidence, that only
verified named consumer edges join package results, and that parent factory
context preserves Focus activity identity.

The host Objective-C fixture uses synthetic UI classes in its own process. It
verifies unchanged stock inputs/results/cache identity, nested package URL and
symbol provenance, suppression of snapshot and unrelated cache reads, the
event budget, and restoration of original method implementations. It neither
loads SpringBoard nor contacts any VM or physical device.
